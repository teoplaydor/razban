# Razban

Portable network privacy & security utility for Windows.

## Downloads

Binary builds for Windows 10/11 (x64) are published on the [Releases](../../releases) page. Each release ships:

- a **portable** ZIP — extract and run, no system install
- an **installer** EXE — per-user install, no admin rights required

SHA-256 checksums are listed on each release page.
