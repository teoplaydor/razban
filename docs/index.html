Network privacy utility

Portable Windows-утилита для шифрования сетевого трафика и применения пользовательских правил маршрутизации на уровне отдельных приложений и сайтов. Базовый сценарий — защита соединений в недоверенных сетях (публичные Wi-Fi, гостевые сети, корпоративные подсети с ограниченным доверием).

Возможности

Per-app маршрутизация

Точное управление: какие приложения работают через защищённый канал, а какие — напрямую. Правила задаются вручную или подбираются автоматически.

Per-site правила

Отдельная маршрутизация для конкретных доменов. Один процесс, индивидуальные пути для разных хостов.

Современное шифрование

Транспорт на базе открытого сетевого ядра sing-box. Поддержка нескольких профилей соединения с автоматическим выбором лучшего по latency.

Адаптивный транспорт

Клиент сам подбирает рабочий профиль соединения для каждого хоста в зависимости от условий сети. Без ручной настройки.

Portable

Запускается без установки в систему: распакуй архив и запусти. Конфигурация хранится в собственной директории, рядом с исполняемым файлом.

Без прав администратора

Установщик ставит программу для текущего пользователя (per-user). Не пишет в HKLM, не создаёт системных служб, не требует UAC.
